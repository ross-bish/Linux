## 💾 1.  Creating a Script:

### Step 1: Start Small
Test this directly in your terminal:

```bash
echo "Wake up, Neo..."
```

### Step 2: Write the Script
1. Open a new file with:
   
 ```bash
 nano matrix.sh
 ```
2. Add the following lines:
   
 ```bash
 #!/bin/bash
 echo "Wake up, Neo..."
 sleep 2
 echo "The Matrix has you..."
 sleep 2
 echo "Follow the white rabbit."
 sleep 2
 echo "Knock, knock, Neo."
 ```

4. Save the file:  
   - Hit **Ctrl + X**, then **Y**, then **Enter**.

---

### **Step 3: Run the Script**
1. Check if the script exists:

```bash
ls
```
2. Run it:

```bash
bash matrix.sh
```

## 🛠️ 4. Positional Arguments: Enter the Matrix

You can pass arguments to the script when you run it:  
1. Update the script:
```bash
#!/bin/bash
echo "Welcome to the Matrix, $1!"
```

2. Run it with your name as an argument:
```bash
./matrix.sh Neo
```

### 💡What are Positional Arguments?
- Positional arguments allow you to pass information (like a name) to a script at runtime, directly in the command line.
- These are accessed within the script using special variables like ``$1``, ``$2``, ``$3``, etc.
- ``$1`` refers to the first argument passed to the script when you run it.
- The script replaces ``$1`` with the value you provide (in this case, ``Neo``).
---

## 🛠️ 5. User Input as an Argument: Neo, Who Are You?

Instead of passing the argument when you run the script, let’s make the script **ask the user** for their name.  

1. Update the script:
```bash
#!/bin/bash
echo "Who are you?"
read name  # Read user input and store it in the 'name' variable
echo "Welcome to the Matrix, $name!"
```
   
2. Save and run it:
```bash
./matrix.sh
```

### 💡How It Works:
- `read` captures the input from the user and assigns it to the variable `name`.  
- The script then uses `$name` to personalize the message.

## 📚💻 6. Pass Command Outputs as Variables
Let’s expand the script with system data:  

1. We have looked at the following commands before, run them to remind yourself what they do. 
```bash
whoami
```

```bash
date
```

```bash
pwd
```

2. Now add these commands to your script:
```bash
#!/bin/bash
user=$(whoami)
date=$(date)
whereami=$(pwd)

echo "Logged in as $user "
echo "Current location: $whereami"
echo "Today’s date: $date "
sleep 2
echo "Wake up, $user..."
```
3. Save and run it!
